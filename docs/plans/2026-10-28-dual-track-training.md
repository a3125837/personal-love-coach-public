# 双轨训练与证据复盘实施清单

目标：融合已讨论的七项通用方法，不导入个人训练原文、分数、经历或分享链接。

1. 保留三题与五维20分，新增首答后的独立分析和教练三项点评；不覆盖原答、不增总分。
2. 增加交流功能与信号清晰度情境标签，仅从登记题目取值；旧数据保留unknown，不更改已有题干摘要。
3. 独立记录跳过/暂时不会回应；统计选题、实际回答、评分及缺失覆盖，不把缺失记0。
4. 教练点评保存判断范围、支持与反证；不把个人倾向固定为通用人格判断。
5. 增加独立虚构情境，练即时修复、行动关心和判断到表达的转换；按需读取详细指南。
6. 先运行针对性失败测试，再跑全部程序、结构、隐私与离线回放检查，保留模型效果验证边界。
7. 核对发布文件与仓库隐私状态，备份并更新本机Skill，提交本轮及前两轮尚未同步的改进，通过非强制更新同步私人仓库。

影响控制：考试未完成前禁止新增教学分析/点评；新笔记不计分、不计晋级题次。旧Schema字段可缺省，新字段按需附加；对象档案和既有评分阈值保持原义。所有笔记只写授权外部数据目录，按锁和原子写入保存。
