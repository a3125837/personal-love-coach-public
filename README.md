# Personal Love Coach · 个人恋爱教练

面向中文恋爱、相亲与长期关系的 AI 教练 Skill，帮助使用者理解互动、自然表达、做出双向选择，并通过练习与复盘提升沟通能力。

**当前版本：3.4.0** · [公开快照仓库](https://github.com/a3125837/personal-love-coach-public) · [版本记录](personal-love-coach/CHANGELOG.md)

本项目提供可加载到 AI 助手中的指令、参考资料、虚构题库和本地记录工具。使用时需要支持 Skill 或读取本地指令文件的 AI 环境；它不是独立运行的聊天网站。

## 可以做什么

| 模式 | 适合的问题 | 主要交付 |
|---|---|---|
| 聊天分析 | “这句话有哪些可能含义？” | 事实、推断、未知与下一步 |
| 回复指导 | “怎样自然地回复或提出邀请？” | 贴合本人语气的建议与简短依据 |
| 模拟训练 | “开始三题综合练习。” | 独立虚构情境、先作答后反馈、多轮接续 |
| 正式考核 | “做一轮无提示考核。” | 三题独立作答、五维评分与晋级条件核查 |
| 约会与婚恋 | “是否继续了解？怎样讨论分歧？” | 双向意愿、现实约束、可验证事项与行动 |
| 复盘成长 | “最近哪里进步，哪些判断需要修正？” | 可比记录、作答覆盖、支持证据与反证 |

也支持按需练习表达好感、轻松调情、接受欣赏、邀约改期、尊重拒绝、冲突修复与长期生活协商。建议围绕真实意愿、适当时机和双方边界展开。

## 设计特点

- **先区分事实与猜测。** 不把回复速度、一次见面或某个表情换算成喜欢概率。
- **关系递进有依据。** P1–P8区分初识、熟悉、好感、暧昧、恋人确认、稳定交往、婚前准备和婚姻经营；好感、当下亲近意愿和关系承诺分别判断，阶段可停留、回退或结束。
- **保留自己的表达。** 自然、直接、温柔或轻幽默都可以成立，不强制每句带反问、调侃或邀约。
- **首答与分析分开。** 先给自然第一反应，再按需分析；教练分别核对理解、实际措辞和最终行动，不让漂亮分析掩盖表达错位。
- **判断可被修正。** 能力观察注明适用情境、支持与反例，不因一次失误给人贴固定标签。
- **记录可追溯。** 新会话绑定题干版本与教学配置，首答、评分、提示补正、接续和分析笔记分别保存。

## 安装与开始使用

### 在 Codex 中使用

1. 下载仓库 ZIP 并解压，或克隆公开仓库：

   ```shell
   git clone https://github.com/a3125837/personal-love-coach-public.git
   ```

2. 将仓库中的 **`personal-love-coach/` 整个文件夹**复制到 Skills 目录：

   - Windows：`%USERPROFILE%\.codex\skills\personal-love-coach\`
   - macOS / Linux：`~/.codex/skills/personal-love-coach/`

   已有同名版本时，先备份自己的修改，再更新。无需把整个仓库放进 Skills 目录。

3. 在新会话中调用：

   ```text
   $personal-love-coach
   开始三题综合训练，先让我给自然第一反应，不要提前给参考答案。
   ```

也可以请求：“帮我分析这段聊天，区分事实和推测，给一个可执行的下一步。”

### 在其他 AI 环境中使用

如果环境支持本地 Skill，按其说明安装该文件夹；如果支持读取项目文件，可明确要求读取 [SKILL.md](personal-love-coach/SKILL.md)，再按入口加载所需参考文件。不同环境的自动发现、文件访问和持久化能力不同。

纯对话辅导不要求运行脚本；本地记录工具需要 **Python 3.10+**，仅使用标准库。模型调用由宿主 AI 环境提供，仓库不内置模型或 API 密钥。

## 使用示例

```text
帮我修改这条回复，尽量保留我的用词，只改最影响理解的一处。

设计三个不同关系阶段的虚构情境，先等我作答，再分别点评理解、表达和行动。

我想练习表达好感。模拟对方的普通回应、转话题或拒绝，看看我能否适当接续或收尾。

帮我复盘最近的训练：同时报告已答、未评分和未回答，不要仅凭平均分判断已经掌握。
```

## 训练与评分

每轮三题。五维分别为自然表达、边界感、反馈判断、互动处理和关系推进，各0–4分，总分20分。

- 单题16分及以上且无重大边界错误为合格；合理维持、收尾或退出也可以得到高分。
- 正式晋级需要同一等级两轮不同题集，每轮三题全部独立通过，并核查未提示、未见题和会话状态。
- 用户分析、教练点评和接续练习不算额外考题，不覆盖首次答案。
- 未回答不记零分；选题数、已答、已评分、跳过和暂时不会回应分别统计。

当前内置 **112道独立虚构案例**：60道训练、42道考题、10道保留评测；Lv0–Lv6每级至少3道训练题和6道考题。另有16条行为评测探针。

阶段模型、难度等级和五维分数都是教练设计工具，不是经过验证的心理测量，也不代表对方的喜欢程度或现实关系成功率。

## 本地记录与隐私

保存前由用户授权，并选择 Skill 目录之外的数据位置。首答、成绩、分析、对象档案与练习记录都应留在独立的数据目录，不提交到本仓库。

本仓库的题目、示例和回放独立虚构，不收录真实私聊、个人训练成绩、联系方式或原始私人分享对话。工具不会自动给对象发送消息，也不会自动上传个人记录。

只有需要记录时才使用脚本。进入 `personal-love-coach/` 后，可先运行：

```shell
python scripts/coach.py validate
python scripts/coach.py question DT-001 --task expression
```

存储授权、会话建立、评分、提示补正和覆盖统计的完整用法见[本地工具指南](personal-love-coach/scripts/USAGE.md)。脚本负责结构校验、存储与计算，语言内容仍需要教练判断。

## 开发验证

在仓库根目录运行：

```shell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -q
python personal-love-coach/scripts/coach.py validate
python personal-love-coach/scripts/build_eval.py
node development/verify_offline.cjs
```

Windows PowerShell运行测试前可设置 `$env:PYTHONUTF8='1'`，统一子进程编码。

3.4.0已有 **100项程序测试**、结构校验与10条离线适配器回放通过，见[验证报告](personal-love-coach/evaluation/reports/verification-3.4.0.md)。离线回放是手写样本，不能证明模型语义质量。真实模型比较、独立人工评分一致性及现实效果仍待验证；第七项旧核心思维缺少原文，未自行补造。
