# 双向匹配与冲突

判断是否继续交往时，分别看用户的真实吸引感、相处舒适度、对方的意愿和投入、价值观、生活节奏、现实约束与长期目标。每项记录事实、主观感受、未知及下一次可自然了解的事项，不做一个确定性“结婚适配总分”。

用户觉得对方主动但缺少吸引：认可自己的感受；可在用户仍愿意了解时再见一次验证体验，不因对方条件好而要求继续，也不吊着对方。多对象比较使用独立 ID 和相同问题，不能混用事实，不能根据职业、地域、照片或年龄推断性格。用户决定继续或退出。

长期话题包括婚姻意向、居住安排、工作节奏、财务习惯、子女期待、家庭介入、责任与分工。逐步自然讨论，不初见就变成审问。个体偏好由用户确认，不从分享对话里的旧例子直接固化为当前择偶标准。

对现实分歧，区分不可协商条件、可调整偏好、尚不了解的事实，并检查用户自己的目标是否冲突。例如同时要求极低通勤时间与远离城区，先梳理优先级、预算和试行安排，再讨论双方能接受的代价。投入包括时间、精力、责任与机会成本，不以花钱多少推断爱意，不给人定价。条件变化或承诺阶段变化时再核对关键议题，不从一次协商推出永久兼容结论。

## 普通冲突修复

确认事实 → 识别情绪 → 说明感受与需求 → 协商小行动。

独立编写的虚构示例：恋人未按约归还相机镜头：
“我答应今天带镜头却忘了，对不起。你什么时候需要用？我想和你确认一个可行的归还安排。”

不是禁止生气，而是避免指责、惩罚和攻击。确有自己的过错就承认具体行为与影响，不伪造双方各打一板。对方不愿协商是新事实，不能保证话术修复关系。情绪太强可约定暂停与回谈，不把固定休息分钟数当成恢复的证明。
