# 关系八段式、信号与兼容情境

## 主辅导模型：P1–P8

此模型来自用户指定分享对话中的实践设计，标识为`eight-stage-v1`。它是关系辅导工作模型，不是已验证的统一心理学标准。平时用阶段中文名称解释，不必每条回复都列代码。证据不足保留unknown；没有具体对象的择偶准备不是第九段。

| 阶段 | 定义与可观察依据 | 当前任务与避免误判 |
|---|---|---|
| P1 初识接触 | 刚认识、交换联系方式或初次交流 | 建立识别和自然开场；加好友不等于恋爱好感 |
| P2 熟悉探索 | 持续交流、了解彼此、愿意接触 | 具体分享与双向了解；专业请教、礼貌和见面次数不能单独证明吸引 |
| P3 好感建立 | 对特定人的欣赏与个人化关注开始可辨认 | 写清是单方、双向还是仍未知；回馈真实好感，不把用户单方心动说成双方互相喜欢 |
| P4 暧昧升温 | 双向好感和自愿的特殊亲近逐渐明显，但未形成恋人共识 | 适度表达与讨论方向；不要求身体接触，不把牵手当作恋人确认 |
| P5 恋人确认 | 双方明确同意以恋人身份认真交往 | 沟通关系期待、排他约定和边界；无需固定表白仪式，也不代表长期适配已验证 |
| P6 稳定交往 | 持续的双向投入、生活安排与关系维护有事实支持 | 协商空间、责任、冲突和价值观；不设固定天数，不要求必须发生争吵才算稳定 |
| P7 婚约与婚前准备 | 双方已共同决定结婚，并开始实际协调婚前事项 | 协商家庭、居住、预算、责任；初识讨论婚育条件或父母催促不等于已达成婚约 |
| P8 婚姻经营 | 据用户提供的事实已建立婚姻关系 | 关注共同生活、分工、亲密和长期协作；婚姻身份不取消独立选择与边界 |

阶段允许停留、跳过、回退或结束，不能按编号强推。无婚姻目标时，不要求进入P7/P8。已婚关系出现普通冲突不自动退回恋人确认；关系结束用独立status记录，保留历史，不创造一个“失败等级”。

## 三条分别判断的线

1. **好感与投入：** 谁表达了什么、是否持续、是否双向。聊得来或认可专业能力不自动等于恋爱意图。
2. **身体亲近与当下意愿：** 一次自愿接触只说明那次互动；沉默、不反抗、此前接受、约会两三次，都不构成继续或其他接触的自动许可。遇到迟疑就停下确认，不用突然接触作测试。
3. **关系共识与承诺：** 恋人身份、排他期待、婚姻决定分别确认。牵手不等于确认情侣；谈婚姻条件不等于共同决定结婚。

例：双方互相表达好感、愿意亲近但尚未谈关系，可暂按P4讨论；如果只是用户单方有好感、对方仍礼貌交流，应说“能确认熟悉探索，你已有好感，对方意愿未知”，而不是宣布双方进入暧昧。

每次有关键新事实时解释：当前能确认什么 → 哪条线仍未知 → 一个最小适当行动 → 何时停下或调整。普通一句回复不展开完整阶段论述。若有明确拒绝，以拒绝范围决定停止，不用P3/P4标签冲淡边界。

## R0–R6：保留含义的旧情境字段

以下仅保留旧档案、题库和v3.0.1图示的语义，不能把这些代码按序改成八段式。新辅导以有证据的P阶段为主；旧字段可以辅助判断任务背景，缺少新事实时不自动填P阶段。

| 阶段 | 定义 | 可观察的转入依据 |
|---|---|---|
| R0 | 准备与择偶 | 尚无具体对象或正在澄清目标 |
| R1 | 初识破冰 | 新认识并开始联系 |
| R2 | 了解与兴趣建立 | 已有双向了解和持续交流 |
| R3 | 邀约与初见 | 双方同意具体见面安排，或首次见面已发生 |
| R4 | 持续约会与双向吸引 | 持续自愿见面、相互投入；不是单次见面就推定 |
| R5 | 关系确认与稳定交往 | 双方明确确认交往或相应关系约定 |
| R6 | 长期匹配与婚姻决策 | 双方开始实际讨论长期共同生活及承诺 |

阶段是工作标签；不明时可保留 `unknown`。允许跳跃、回退与结束，但每次变化须记录事件、时间、依据。只约了时间不等于已经见面；单方称“女朋友”不替代双方确认。新认识另一对象不能继承旧对象阶段。

兼容解释：R1常见于P1，但要核对事实；R2和R3可能涉及P2–P4，邀约/初见本身不能确定好感程度；R4不自动代表P4或确认恋人；R5原来合并了确认与稳定，新增事实才可细分P5/P6；R6原来是长期/婚姻决策任务，不能据此认定已婚P8。R0表示准备，不映射八段式。

持久化时旧`stage`/`stage_history`不改义。需要八段式记录时，另加`relationship_phase`（P1–P8或unknown）与`phase_history`（phase/date/evidence）；无依据不能写确定阶段。历史只能追加修订事件，不能删除过去判断。新旧字段不一致时核对各自日期、事实和来源，不静默覆盖，也不把旧字段当成最新共识。

阶段与关系状态独立：`active`、`paused`、`ended`。取消首次邀约可回到 R2 或保持 R3 并说明原因；分手将状态设为 ended，保留历史而非改为 R0 假装从未交往。重新联系先确认意愿和现状，不能自动恢复旧阶段。

## 信号分级

| 等级 | 可用依据 | 推荐动作 |
|---|---|---|
| S3 积极 | 多次主动、延续话题、分享或自愿落实见面等多项行为 | 结合阶段适度推进 |
| S2 开放 | 愿意交流、基本配合，主动性尚不明显 | 保持交流，条件合适可轻邀约 |
| S1 模糊 | 单次简短/延迟回复、记录不足 | 不判定喜欢或不喜欢，最小合理行动 |
| S0 消极 | 明确拒绝、连续回避或持续无回应 | 按拒绝范围停止、降低投入或退出 |

同时检查主动性、延续性、自我披露、线下意愿、持续性，不机械算总分。不把礼貌、表情或一次买单当承诺，也不把慢热当低投入的永远借口。明确拒绝优先。
