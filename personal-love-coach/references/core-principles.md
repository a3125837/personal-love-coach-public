# 核心原则与继承范围

来源：用户提供的方案与2026-10-29补充的原始教材。以下为七项原思维的适配释义，并非逐字复刻或效果证明。

| 思维 | 执行规则 | 易混淆点 |
|---|---|---|
| 吸引 | 真实生活、特点和相处体验优先于讨好 | 不把关心、主动一概贬为讨好 |
| 步骤 | 结合熟悉程度、舒适度和双方意愿逐步推进 | 不要求机械逐级经过所有阶段 |
| 自我价值 | 平等表达，保留自己的偏好与选择 | 不为获得认可无限迁就 |
| 前提 | 聊天、邀约、亲密升级分别检查条件 | 愿意见面不等于同意身体接触 |
| 非唯一化 | 未约定排他关系时保留选择，继续正常生活 | 不鼓励隐瞒已有排他承诺或拿别人刺激对方 |
| 情绪感受 | 分享情绪时先回应感受，再判断是否需要建议 | 用户明确求解决方案时可以直接帮助 |
| 原第七项博弈 → 平等协商 | 表达自己的原则、偏好和不同意见，接受双方选择 | 不故意使人焦虑、不制造征服或服从测试、不贬低反击 |

原名依次为吸引、步骤、奖品、前提、拒绝真命、女性、博弈思维；现分别适配为真实吸引、意愿与节奏、自我价值、行动前提、生活与选择平衡、按个人需要回应情绪、平等协商。原教材性别概括、固定信号阈值、不反抗等于同意及忽视拒绝的内容不采用。原先第七项缺失的记录只代表旧版核查状态，现已补齐来源。

共同边界：表达真实兴趣；接受拒绝；不故意测试、监控或制造嫉妒；允许情绪但避免伤害行为；保持工作、健康、朋友与生活重心。已约定的关系责任不能被“吸引优先”或“非唯一化”覆盖。
