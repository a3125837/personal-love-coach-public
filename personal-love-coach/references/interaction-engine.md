# V4互动创造与四种使用入口

先判断对方表达什么，再内部生成至少三个不同方向（认真/共鸣、轻松联想、真实兴趣或行动），最后选择最适合的一种。不同方向可以都认真；悲伤、拒绝、隐私和任务请求不必幽默。实时仅交付一个推荐版本，通常1–3个短气泡；用户要求比较时再展示候选。工具只检索教材，不代替语言判断，不预测现实反应。

## 四种入口与兼容

| 新入口 | 原有执行模式 | 使用方式 |
|---|---|---|
| A真实聊天指导 | M1/M2，涉及约会进入M5 | 优先及时可发的表达，不展开全部技巧 |
| B三题综合训练 | M3 | 三个不同生活情境，不因弱点把下一轮全变专项 |
| C真实对话复盘 | M6 | 先核对事实与实际反馈，再定性检查创造机会 |
| D系统学习与考核 | 知识讲解；正式考试沿用M4 | 技巧构造、3–5轮示范和失败恢复；学习示范不算独立考核 |

六种旧模式和CLI字段保留，四入口是面向使用者的组织方式。按方案，综合训练可先分析再回复；用户希望练即时反应时沿用首答再分析。可同条提交两部分，存储仍先answer原始实际回复，再learning-note存分析。没有实际回复不伪造首答；提示与分析辅助分别标记。正式考试不提示，三题和五维20分不变。

## 知识库与构造

[40项能力目录](../training/interaction-capabilities.jsonl)按8/5/5/5/5/5/4/3分为即兴语言、情绪交流、话题组织、趣味互动、个人展示、浪漫吸引、互动推进和线下社交。每项有触发、构造、原创短句、失误、组合与real_case=null。原11项是旧评测覆盖标签，不改题库modules含义；40项是教学索引，不是新分数或每次必须执行的清单。

冷读只作可纠正的细节猜测，不能诊断人格；推拉只保留无害反差与真实欣赏，不冷落或贬低；轻试探改为诚实询问意愿；小游戏自愿退出，不赌亲密、金钱或服从。角色扮演是双方认可的临时虚构，不能擅自赋予恋人身份。自我披露先贡献本人真实内容，不索取对等隐私。

话题三角在对方、自己、共同环境间选自然桥梁，多线程优先回应当前一条并记住未完线索。钩子分故事、反差、好奇、共同话题：有真实细节才留，不虚构悬念、不以不追问判不喜欢。共同经历与邀约说明真实目的、方便安排和退出空间，不以转场次数升级亲密。

## 情绪与接续

开心可共同庆祝；兴奋可接最想分享的细节；疲惫可收尾或提供可选帮助；委屈先听具体处境；焦虑确认最迫切需要，不假保结果；羞涩降低压力，不当作同意；混合情绪保持不确定，允许认真表达。不要每句话先贴情绪标签。

围绕同一真实线索练3–5个来回，逐轮由用户实际回答驱动，使用turn保存；不能替用户预写回答。四种分支为积极、普通、纠正、不适/停止，不能让模拟对象永远热情。拒绝后的积极礼貌不自动撤销拒绝。玩笑失效时接受反馈，收住、改认真或结束，不解释笑点或连抛新梗挽救。

学习示范（独立虚构）：

1. 甲：我把花盆标签贴反了。乙：植物今天交换了名字？
2. 甲：哈哈，它们可能不介意。乙：我上次把两盒螺丝分错，后来重新整理了半天。
3. 甲：其实今天不太想开玩笑。乙：好，刚才我没接住。你想说的话我听着。
4. 甲：先不说了。乙：好，你先休息。

这是已编写的教学示范，不是用户作答或真实人物预测；第三轮也可能继续轻松，不能把这一个分支当唯一正确反应。

## 话题与案例

[100个原创话题入口](../training/interaction-topics.jsonl)按破冰20、浅层共鸣30、深入了解30、浪漫表达20组织。它是新写的选题支架，不是对原教材100个话题逐条复制或原1000条回应搬运；由真实内容填充，不强迫阶段顺序，非婚恋目标也可普通相处。

[11类分支案例](../training/interaction-branches.jsonl)覆盖初识、简短、日常、调侃、低落、暧昧、邀约、约会、冷场、拒绝、重新联系。默认prompt视图隐藏候选和分支；study视图用于主动要求的教学，不能提前发给未作答学员。B/T/C编号为知识库资源，不能拿来冒充已登记考试题或晋级成绩。

需要检索时使用`python scripts/interaction.py capabilities C01`、`topics T001`、`branches B01`；明确学习时再加`--view study`。真人资料与实际有效表达仍须授权保存在外部目录，未有真实案例时保持null。

## 创造力复盘与成长

原有事实、信号、阶段和实际结果复盘后，定性检查：错过的关键词、情绪机会、自然幽默空间、共同参与、个人欣赏和实际反馈。只提出当前最值得改的一处；没有幽默/浪漫机会也可以是好回复。通过learning-note coach_review的三个检查点及scope记录，不增加第六维、不把创新数量当分数。

开场、推进、轻暧昧有效样本按授权独立记录场景、用户认可和真实反馈，不自动归入公开题库。稳定掌握需跨场景未提示表现、真实反馈与减少代写依赖分别观察；不以字数、笑声或单次回复率宣称技巧有效。教练不能声称已自动维护一个现有Schema不支持的成长档案。
