# 3.2.0优化与验证记录

日期：2026-10-28。主体仍是个人恋爱教练：六模式、11项能力、P1–P8、三题、五维20分及现有晋级机制。外部项目只提供概念比较，未复制代码、对话、角色脚本或受限资源。新增示例和探针均独立虚构，没有读取或使用私人材料。

## 已落实的优化

1. 证据：明确材料覆盖范围、来源和结论范围，区分缺失与不存在，观察线上线下差异，支持证据与反证一起考虑。
2. 决策：一个主要目标、最小行动、适用前提与失效条件；按积极、普通、拒绝反馈调整，考虑共同工作和公开场合成本，减少重复读心。
3. 表达：保留用户声音与可用草稿，按即时帮助、先答、检查点逐渐减少辅助；不强制玩笑、反问或暧昧。
4. 调情：新增按需指南，覆盖具体欣赏、共同小场景、活动轻挑战、直接表达；区分关系阶段与当下状态，补上接续、转向、收尾、致歉和停止。
5. 教学：表达、判断、信息收集、适应四类目标；判断题不先揭示阶段，新增白名单题面工具；三题内可加短接续，首答评分、提示后练习与现实反馈分开。
6. 评分：接受多种合理表达，不按参考答案相似度、不按模拟对象热情评分；沿用rubric-3.0，未改变分值、阈值或旧数据含义。
7. 现实关系与复盘：梳理底线、偏好、未知和目标冲突；区分投入与爱意；提醒片段选择偏差，发现新事实就复核旧建议。
8. 记忆与纠正：事实、归属、风格与猜测分类；旧状态标日期和来源，只回忆当前对象相关信息；明确暂停、查看、删除与备份的区别，不让append-only阻碍授权删除。

修复了两处题干/解析错位：自行车反复损坏对应失望与故障情境；居住偏好分歧对应底线、可协商偏好与试行安排。

## 已执行验证

- 65项Python回归通过，含新增6项题面/任务约束/评测隔离测试；现有保存、恢复、题源与晋级回归继续通过。
- Skill元信息与包内链接、题库结构校验通过；原58题及独立虚构来源标记保持一致。
- 10条手写离线回放用于验证配置与适配器，不是新模型输出。

新增8条`evaluation/behavioral-regression.jsonl`覆盖局部证据、当下状态、拒绝修复、判断题泄漏、多种有效表达、事实纠正、现实约束和成长误判。该组只支持真实候选模型加评审模型，不提供手写回放伪装通过。可生成配置：

```shell
python scripts/build_eval.py --suite behavior --provider YOUR_CANDIDATE --judge YOUR_JUDGE --output /chosen/behavior-config.yaml
```

将占位符替换为环境支持的真实provider，再通过自行配置的评测环境运行；生成配置不代表已经调用模型或通过评审。本轮未运行真实模型语义比较与人工盲评，不能据此宣称建议质量或现实恋爱效果已经得到验证。

## 能力边界

题面工具不改写原题干，仍需教练检查原文是否包含待考结论。现有脚本保存每题首答和评分；多轮接续仅在会话中练习，用户要求留存时另行导出，不宣称可由`show-session`恢复接续。记忆管理新增的是执行规则，没有新增自动删除CLI、原始聊天导入器、人物模拟器或后台代理。交互图仍为既有历史快照。
