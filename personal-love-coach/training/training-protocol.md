# 训练状态与等级

两条路径：按等级的系统训练，或从实战弱点生成综合情境训练。默认不把每项能力拆成孤立专项：仍是综合三题，在解析中指出弱点涉及的能力，并在下一轮新情境增加该能力的练习机会。用户明确要求专项时才切换。用户随时提出即可启动，不自行设定必须按周完成的计划。共同使用五维20分。

| 等级 | 目标 |
|---|---|
| Lv0 | 边界、事实与基础信号 |
| Lv1 | 自然破冰 |
| Lv2 | 延续、分享、回应与轻幽默 |
| Lv3 | 判断窗口、邀约、改期和拒绝 |
| Lv4 | 线下互动、冷场与持续约会 |
| Lv5 | 冲突、承诺、价值观与匹配 |
| Lv6 | 多轮混合信号和复杂综合决策 |

等级表示训练难度，与是否有伴侣无关。初诊不足时从低风险基础题开始；不凭职业、年龄或旧对话描述自动赋等级。

状态：`diagnostic → awaiting_answers → feedback → retry/next_round`；考核为 `exam_awaiting_answers → exam_feedback → passed_round/needs_practice`。中途切到实战保存当前题号和已答内容；恢复时不重置成绩或把提示题当独立作答。

以上为教学概念状态。实际存盘使用 `awaiting_answers / feedback / paused / completed`，模式单独用 `training / exam`；diagnostic对应初诊阶段，passed_round/needs_practice是评分结论，不写成脚本不支持的状态。原答、分数和题目来源分别持久保存并关联，不能只填answered_case_ids冒充已答。

每轮固定三题；部分回答只评价已答部分并等待剩余，不宣称整轮完成。每题保留首次回答、是否提示、五维分、错误、重大错误、案例 ID、等级、类别和评分版本。新会话还绑定题干快照、内容摘要、语料版本与逐题任务设置，恢复沿用这些信息；旧资料保留可读但不自动补造版本。改写后的高分不能覆盖首次低分。首答提示标记遗漏时用correct-hint保留审计补正，首答之后才出现的提示属于后续练习。

提示渐退：用户先答 → 只指出关注点 → 必要时给公式 → 作答后给示范。练习可请求示范，但标记 assisted；正式考核不得提供。下一轮优先换情境重练最弱维度，而非机械增加难度。

首答与事后分析分开，详见[双轨训练](dual-track-training.md)。不强制先分析才能说话，不把事后分析或改稿当首次自然反应。教练同时检查理解、实际措辞与最终自愿行动，但不增加评分维度。没有回答、跳过、暂时不会回应分别记状态，缺失不计0；报告覆盖率和提示状态，避免只统计已答题造成偏差。正式考核完成前不收教学分析或点评，仍先独立三题首答。

出题先选任务：表达题练自然回应，可提供阶段背景；判断题让用户区分事实与推断，不展示预设阶段；信息收集题让用户找出会改变决策的关键问题，不预告缺失信息；适应题在首答后逐步给出虚构新反馈，观察是否调整。题型是教学目标，不另造评分维度。需要新题时只独立创作虚构场景并注册，不能把考试题或私人材料改名充数。

用`scripts/coach.py question CASE_ID --task judgment`生成安全题面；只有表达题可加`--include-phase`。该工具只白名单输出题干和任务，不输出facts/unknowns/expected/failures等内部字段；不会自动删除原题干已经包含的提示。教练仍需检查题干是否泄露待考结论、是否适合选定任务，不适合就换题或独立创作。三题可分别练表达、判断、信息收集；并非每轮都要同一配方。

需要多轮接续时按[调情与互动校准](../references/flirting-and-calibration.md)中的接续协议执行；普通对话也可使用。接续与首次评分及考试资格分开，不把三轮对话冒充三个新题。正式考核仍以注册的三题与首答机制为准，不在首答前用追加信息暗示答案。

阶段相关综合题先读取[八段式](../references/relationship-stages.md)。教练内部判断当前可确认阶段、信息缺口和本次行动是否跨层级；反馈时解释为什么这样回应/邀约/讨论关系适合当前阶段，而不是只给一句答案。阶段错误归入反馈判断或关系推进，不增加第六维，不要求用户在每句聊天中报阶段代码。题目中的P阶段是教学背景，不能据此更新用户的真实对象档案。

一次通过只说明这次表现；希望稳定时继续换场景练习，并做无提示复测。不要仅用训练轮次、平均分变化或AI模拟的热情反应证明现实能力提升。真实行为反馈可修正此前判断，不能因某次模拟不会回就认定用户不敢行动或没有推进能力。

题目合格阈值与晋级按评分量表及 M4。延迟复测默认建议 3/7/14 天（首版可调整设计值）；同类新题复测，不能只背答案。提示减少、同难度独立表现和真实行动记录分别统计。

错误分类：`comprehension` 理解、`evidence` 判断、`expression` 表达、`interaction` 接话、`action` 行动、`boundary` 边界。类别允许多个，不贴人格标签。
