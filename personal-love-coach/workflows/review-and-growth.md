# M6 复盘与成长

六步：事实 → 信号 → 自己的行动及理由 → 对方实际反馈 → 替代方案 → 下次实验。区分决策质量和现实结果，不能从单个对象推导性别规律。

检查记录覆盖范围：只汇报顺利或受挫的片段会影响判断，材料缺口应直接说明，不能补造未报告事件。把首次独立表现、提示后的改写、重复题、接续练习和真实反馈分开；模拟对方变热情不构成训练有效证据。新反馈推翻旧假设时，注明哪条判断失效及需要调整的行动。

读取数据规则；有授权历史则比较相同等级、类别、评分版本与首次作答的表现。分别报告五维分数、独立合格率、同类稳定性和实际行动完成度；没有数据就明确没有，不显示虚构上升曲线。

建议一个能自主完成的小实验，例如下一次先自己写自然回复，发送前只核查真实与边界。现实行动完全由用户决定，不自动发送、不强迫见面。安排 3/7/14 天的可选复测仅写入记录，不等于已经建立提醒。

发现同类弱点：理解错误 → 事实拆分；判断错误 → 多解释与证据；表达错误 → 保留原意改一处；行动错误 → 窗口、拒绝与停止条件。延迟用不同情境检验迁移。

按[双轨与证据](../training/dual-track-training.md)复核教练自己的假设：困难出现在哪些情境，是否存在成功反例，旧判断是否过宽。支持、反证与未验证部分分别记录，不把倾向写成人格。使用coverage补充选题数、已答、未评分与缺失状态；题目位置不等于能力类别，缺失较多的类别不能仅凭已答平均分判断擅长。旧情境标签保留unknown，不根据个人画像反推补齐。
