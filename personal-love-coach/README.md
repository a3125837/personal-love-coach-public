## 使用

将整个 `personal-love-coach` 文件夹放入目标环境的 skills 目录。在 Codex 中默认位置为 `~/.codex/skills/personal-love-coach`。新会话通过 `$personal-love-coach` 显式调用，也可通过自然恋爱辅导请求选择。

- “帮我分析这段聊天，给一个下一步。”
- “这句话怎么回比较自然？”
- “开始三题训练，先不要给答案。”
- “参加正式考核。”
- “相亲见面后我有些犹豫，帮我判断是否继续。”
- “复盘我的训练表现。”

纯文本辅导不要求脚本；本地数据工具需要 Python 3.10+，详见 [工具用法](scripts/USAGE.md)。个人数据必须在 Skill 目录之外，打包仅包含 Skill。

3.0.1增加了原答即时保存与会话恢复，考试题源/等级/提示/完成状态交叉核验，修复了独立全流程测试发现的晋级及断点恢复缺口。

本轮实际执行情况见 [3.0.1验证摘要](evaluation/reports/verification-3.0.1.md)：51项程序测试、59条流程命令和独立内容检查。结论限于模拟与工具流程，不是现实恋爱效果证明。
