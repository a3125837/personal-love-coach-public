# 个人恋爱教练 · 4.0.0

面向中文恋爱、相亲与长期关系的 AI 教练 Skill，帮助用户独立判断、自然表达与双向选择。

## 使用

将本文件夹完整放入宿主环境的 Skills 目录。Codex 默认位置为 `~/.codex/skills/personal-love-coach/`，新会话输入 `$personal-love-coach` 调用。入口与按需加载规则见 [SKILL.md](SKILL.md)。

四个入口：A 真实聊天、B 综合训练、C 复盘成长、D 系统学习与考核；底层保留六种工作模式。可以直接说：

- “分析这段聊天，给一个下一步。”
- “开始三题训练，先等我回答。”
- “练习自然表达好感，以及收到普通回应或拒绝后的接续。”
- “做一轮无提示正式考核。”

## 4.0.0 能力

新增[互动创造引擎](references/interaction-engine.md)：8 模块 40 项能力、100 个原创话题入口、11 类分支案例，支持多方向表达选择与 3–5 轮连续模拟。教学资源独立于原评分题库。

关系辅导采用 P1–P8 八段式，分别判断好感、当下亲近意愿和关系共识。训练仍为每轮三题、五维各 0–4 分、总分 20 分，保留 Lv0–Lv6 晋级规则。

原评分题库共 112 道独立虚构案例：60 训练、42 考试、10 保留评测，另有 16 条行为探针。首答、分析、点评与接续分别保存，不互相覆盖；明确拒绝优先于模糊积极信号。

## 工具与数据

纯对话辅导无需运行脚本。本地记录、检索与结构校验需 Python 3.10+，仅使用标准库，见[工具指南](scripts/USAGE.md)。脚本不自动生成语言建议或评定语义分数。

保存前需获得用户授权，个人数据应置于本 Skill 文件夹之外。内置案例和示例独立虚构，不包含私人聊天或原始教材；不自动发送消息或上传记录。

## 验证与说明

4.0.0 通过 106 项程序测试、结构校验及 10 条手写离线回放，见[验证报告](evaluation/reports/verification-4.0.0.md)。程序与离线检查不证明真实模型质量或现实恋爱效果。阶段与分数均为辅导工具，不是心理测量。
